## 前回のお願いを一つ訂正します ← 先に読んでください

**白・黒・灰は、無理にずらさないでください。**

「専用色を増やしてください」とお伝えしたせいで、v3より前の納品では
白がわずかにずらされていました(#F1F1EF #F1F1F0 #F2F1F0 …)。

v3では白が同じ白に揃っていて、**そちらが正しい**です。
「枝雪の白」も「冠羽の白」も、どちらも白であるべきです。

こちらの点検も、無彩色を数えから外すよう直しました。
**白を白と置いても減点されません。**

散らしてほしいのは**色みのある色**だけです。

以下、次回さらに良くするためのお願いです。

## 1. 色名は「役割」ではなく「実在するもの」を指してください ← 最重要

v2で採用を見送った160件は、**すべてこれが理由**でした。

このアプリは**色名を画面とPDFにそのまま印刷します。**

採用した国・地域はここが良かったのです。
`バティック藍` `蜂蜜石` `ポウナム緑` `泥炭茶` `ヒース紫` — すべて実在の指示物です。
**この水準を全分野で保ってください。**

## 2. 色の重複は「完全一致」ではなく「見た目」で自己点検してください

v2は完全一致では1200色すべて異なっていましたが、
**知覚差(CIE Lab の ΔE)でまとめると602群**でした。
`#E0DEDD` `#E1DEDC` `#E1DFDC` のような**見分けのつかない差が最大45色**重なっていました。

次回は納品前にこう確かめてください。

- 全色を Lab に変換し、**ΔE < 3 の色どうしは同じ色として数える**
- その上で「1項目あたり、その項目だけの色が何色あるか」を出す
- **1.0 / 5 を下回る分野は出さない**(こちらで不採用になります)

微差でずらして数を合わせても、こちらの点検(`tools/audit-incoming.py`)で分かります。

## 3. 説明文は穴埋めにしないでください

v2は240件すべてが同じ形でした。

## 4. 修飾語は「語数」ではなく「軸」を増やしてください

50語いただきましたが、こちらの仕組みに落とすと**30通り**になり、
うち**13語は何も起きません**(`finish` `warmth` `harmony` `pearl_mix` など未実装の軸のため)。

**明度と彩度だけを動かす語は、いくつあっても10〜15通りに収束します。**

ただし、ご提示の軸そのものは示唆的でした。次はこの3つを設計してください。

- `finish: metallic / pearl / matte` — ビーズの加工そのもので、実用性が高い
- `hue_shift` — 色相を動かす軸。明度・彩度だけでは出せない変化
- `harmony: 同一色相 / 類似色相 / 補色` — 配色技法と対応するので、そのまま使える

## 5. できればこの形式で納品してください

JSONからの変換をこちらで挟まずに済みます。CSV(UTF-8)で、見出しはこの通りに。

```
表示名,反応することば,ひとこと,色1,色1の名前,色2,色2の名前,色3,色3の名前,色4,色4の名前,トーン,質感,配色技法
```

- **反応することば** — `|` 区切り。日本語・英語・別表記をまとめて
- **色は4色** — 5色目は使っていません。`#RRGGBB` かTOHOの品番(例 `557`)
- **トーン** — PCCSの記号を `|` 区切りで。使えるのは
  `v b s dp lt sf d dk p ltg g dkg` のみ
- **質感** — 空欄 / `ラメ` / `ツヤケシ` のいずれか
- **配色技法** — 次の18語のいずれか、または空欄。**表記も完全に一致させてください**

```
同一色相配色 / 類似色相配色 / 中差色相配色 / 対照色相配色 / 補色配色 /
対照トーン配色 / ドミナントカラー配色 / ドミナントトーン配色 /
トーン・オン・トーン配色 / トーナル配色 / 色相のグラデーション /
トーンのグラデーション / ナチュラルハーモニー / コンプレックスハーモニー /
セパレーション / リピテーション配色 / カマイユ配色 / フォ・カマイユ配色
```

## 9. 色名は、実際の色と一致させてください ← 今回いちばん多かった点

重複はきれいに消えていました。ありがとうございます。
今回見つかったのは別の種類の問題で、**色名がその色を言い当てていない**ものです。

```
✗ 香灰の白    #585C6B  → 実際は暗い灰青(明度38)。白ではありません
✗ 屋台の漆黒  #3F4D66  → 実際は青灰(明度32)。漆黒ではありません
✗ 黒胡麻の黒  #414360  → 実際は濃い青紫。黒胡麻は黒です
✗ 樹脂の焦茶  #D03033  → 実際は純粋な赤です
```

とくに**「黒」と名付けた色が濃紺・濃紫になっている**例が5つありました。
色を互いに離そうとして、名前から離れてしまったのだと思います。

**色を散らすことと、名前に忠実であることは両立させてください。**
散らすために名前と違う色にすると、画面には
「黒胡麻の黒」という名前の隣に濃紺の玉が並ぶことになります。

納品前に、色名に色の語(黒・白・赤・青・緑・金・茶など)が入っている色は、
**実際にその範囲の色相・明度になっているか**を確かめてください。

なお `伽羅` は4色すべてが名前と食い違い、香木らしさも出ていなかったため、
こちらで書き直しました。

## 12. 同じ項目の中で、同じ色を二度使わないでください

v4で2件ありました。

```
✗ ベニカミキリ      #111111 が2回 — 「頭部の黒」と「脚の黒」
✗ キオビヤドクガエル  #111111 が2回 — 「体表の黒」と「瞳の黒」
```

**4色のはずが実質3色になります。**
黒を #111111 に揃えていただいたのは正しいのですが、
その結果、同じ項目の中で黒が重なってしまったようです。

一方が黒なら、もう一方は別の要素にしてください。
ベニカミキリなら「竹の淡黄」、ヤドクガエルなら「腹の青灰」のように、
**その生きものの別の部位や、生息する場所の色**にすると4色が生きます。
