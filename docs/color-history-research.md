# 色彩史リサーチノート(2026-08-24)

8つの色彩史・配色サイトの調査まとめ。COLOR STORY PALETTE の辞書拡張の素材とする。

## 各サイトの要点

### 1. VISCOLOR (viscolor.cn)
世界32カ国・106の伝統色アーカイブ。「色は文化を運ぶもの」。
- 辰砂赤(中国、新石器時代〜。秦以降は公式印鑑の色)
- インディゴ/藍(日本、江戸の浮世絵。ゴッホに影響)
- サフラン(インド、ヒンドゥー・仏教の聖色)
- エジプシャンブルー #1034A6(BC2200頃、人類初の合成顔料)
- マヤブルー(パリゴルスカイト粘土+インディゴ、雨神チャックの儀式色)

### 2. VISCOLOR タイムライン(6時代区分)
1. 〜BC3000「鉱物と土の始まり」: エジプシャンブルー #1034A6、シナバー赤 #FF461F
2. BC3000〜500CE「古代帝国の色秩序」: +サフラン #F4C430、ペルシャンブルー #1C6E8C、帝国黄 #FFD700
3. 500〜1200「宗教美術と釉薬革命」: 空色 #87CEEB、月白 #D6ECF0、藍 #1B4B7A
4. 1200〜1500「シルクロード色彩の頂点」: コバルト #1E4D8C、イズニックブルー #1B4B7A、ペルシャターコイズ #40E0D0
5. 1500〜1800「大航海時代と宮廷」: フランスブルー #318CE7、ベルサイユゴールド #D4AF37、ベルサイユレッド #B22222
6. 1800〜現在「産業色と世界的復興」: 墨黒 #1A1A1A、クリシュナブルー #1E3A5F、ホーリー赤 #E74C3C

### 3. Pigmentoria
美術史の色彩百科(600色超)。絵画21時代・69作家414色、映画6時代36色、写真14技法84色、非西洋8時代72色。
注: 色は「美術史的分析に基づく解釈的復元」であり厳密値ではない。

### 4. Palette Atlas
文化パレット集(日・韓・中・モロッコ・メキシコ×各10)。日本のパレット名が秀逸:
江戸商人 / 平安貴族 / 侘寂茶室(室町〜桃山) / 武士甲冑(戦国) / 歌舞伎舞台 / 桜春。
→ 辞書の「言葉」の発想源として優秀(HEXは非公開)。

### 5. Storied Colors
1日1色、来歴・化学・犠牲まで語る色カタログ(252色、毎週日曜更新)。
- ラピスラズリ #26619C(BC3000、アフガニスタン産)
- ベルディグリス(BC300、銅板を酢で腐食させて採る緑。紙を蝕む)
- バーミリオン(BC300、硫化水銀。鉱夫の命と引き換え)
- シャルトルブルー #1F3F8E(1145頃、大聖堂のステンドグラス)
- ウランレッド #D7350F(1936、放射性)
→ 「色の物語」の文体のお手本。負の歴史(毒・禁令)も含めて語る。

### 6. Colourant Mapping Project
考古学の染料・顔料使用例のオープンDB(エジプトの棺、ポンペイ、着色ガラス、貝紫の織物)。
トップページに具体データなし。/map と /entries に詳細。

### 7. Mapping Color in History(ハーバード大)
アジア美術の顔料の科学分析データベース(Jinah Kim教授)。作品単位で顔料の出現を時空間トラッキング。
学術的裏付けの参照先として有用。

### 8. Dictionary of Color Combinations(colorcombinations.org)
**和田三造『配色事典』(1933)の完全デジタル版。348の歴史的配色をHEX/JSONで無料公開。**
- 理論記事: 平安の襲と季節暦 / 4種の赤(紅・茜・朱・鉛丹)の使い分け / 侘寂 / Japandi / 北欧
- 配色例: 紅と紺(平安)、桜と若竹(平安)、浅葱と朱(江戸)、刈安と利休鼠(室町)、江戸紫と鼠(江戸)…
→ **アプリ取り込み候補の本命**。1933年刊でパブリックドメイン。348配色のJSONデータが流通している
  (GitHub: mattdesl/dictionary-of-colour-combinations 等)。

## 学んだことの整理

1. **色の歴史は「顔料の技術史」**: 人類初の合成顔料(エジプシャンブルー BC2200)→ラピスラズリの奢侈→
   1856年パーキンのモーヴ(合成染料)→産業色。技術の節目が色の民主化の節目。
2. **色には代償の物語がある**: バーミリオンは水銀、ベルディグリスは腐食、ウランレッドは放射能。
   「美しさの裏の犠牲」は物語として強い。
3. **日本の配色は「言葉+時代+身分」の三点セット**: 平安貴族/江戸商人/武士甲冑のように、
   時代×立場でパレットが変わる。四十八茶百鼠(江戸)はその極み。
4. **和田三造の348配色は昭和8年の日本人の色感覚の記録**であり、権利的にも使える一次資料。

## アプリへの取り込み候補(優先順)

1. **和田三造348配色**: sanzo.json として同梱し「三造モード」or 辞書の配色ソースに。
2. **古代・顔料の物語エントリ**: エジプシャンブルー、マヤブルー、ラピスラズリ、シナバー、
   ベルサイユ、イズニック、シャルトルブルー等を辞書へ(HEXはVISCOLOR/Storied Colorsを参考)。
3. **紀元前〜中世のタイムライン拡張**: 現在1400年までの年号解釈を「BC3000」「古代」「中世」等の
   語で拡張(VISCOLORの6時代区分が骨格に使える)。
4. **文化パレット語彙**: 歌舞伎、武士、侘寂、ポンペイ、シルクロード等の言葉を追加。
